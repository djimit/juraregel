# JuraRegel engineering invariants

1. Governance evidence is not a legal rule, compliance score or certification.
2. Missing evidence fails closed as `insufficient_evidence`; metadata alone
   cannot promote it to `review-ready`.
3. JREM source references remain versioned, typed and reproducible.
4. Catalog-only use cases do not expose simulated calculations as decisions.
5. Crosswalks express typed analytical relationships, never automatic
   equivalence.
6. External-system integration claims require versioned observed evidence;
   static mappings prove only mapping completeness.
7. Human legal, risk and release decisions remain explicit and
   non-compensable.
8. The canonical gate executes product, API, documentation and root assurance
   tests that support published claims.

Changes affecting these boundaries require a regression test demonstrating the
failure mode.
